# Audi Quattro Interactive 3D Showcase

A single-file interactive showcase for the 1990–1991 Audi Quattro (Typ 85). The car model is generated procedurally in the page; Three.js and OrbitControls are loaded from a CDN. Local gallery images are in `assets/gallery/`.

## Controls

- Drag to orbit; right-drag to pan; scroll to zoom.
- Click a part to inspect it; double-click to frame it.
- Use `1`–`6` for camera presets, `E` to explode, `A` to assemble, `L` for lamps, `W` for wireframe, `Space` to toggle auto-rotation, and `R` to reset.

## Run locally

Open `index.html` in a modern browser with an internet connection for the Three.js scripts and fonts.

## Deploy

Enable GitHub Pages for the `main` branch and repository root (`/`).
